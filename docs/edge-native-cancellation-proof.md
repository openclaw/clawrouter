# Isolated edge cancellation proof

This is an offline preparation route for an **instrumented frozen-candidate edge composition**. It does not deploy resources, enable a service, qualify a production release, or prove another provider's cancellation behavior. Cloud deployment, the actual SDK controls, protocol observations and remote retirement remain unrun until separately authorized.

The server source is frozen at `5cfafe8c8df43102365ec900431b8b3be1dd4eb0`, tree `6da1d6ea30f74d18730365c875b2978c61f34ce2`. The builder reads tracked Git objects into a private capsule. It does not merge the candidate's unpublished provider changes into this branch. The four dependency inputs must match the frozen materialized build root; directly building an incompatible current checkout still fails this equality. The SDK consumer is frozen at `d8bb939408aa4d2be7df0161748edb52ebf3b1fb`.

The capsule also contains byte-exact copies of the qualified `stream-chain` and `stream-json` runtime packages, with per-file hashes. This is a bounded build input copy, not an install. Esbuild uses its normal resolver inside that capsule; emitted module identifiers contain no private checkout or temporary paths.

### Runtime isolation and supervision

The parent correlates the daemon's exact per-container metadata paths with filesystem device/root entries in its own and the target's kernel mount tables; those target mounts must be read-only. It does not traverse Docker's root-owned storage. Ambiguous or changing mappings fail. `/task` is a 2 GiB noexec/nosuid/nodev tmpfs, inside a 4 GiB memory limit with no extra swap; the process limit is 128 and CPU limit is two cores. HOME, XDG, temporary files and logs are created there before use.

The parent records all four real/effective/saved/filesystem UID and GID columns and its exact supplementary groups. ### Explicit PID1 drain barrier

The image compiles `config/edge-proof/reaper.c` with its existing qualified GNU toolchain; no compiler or package is downloaded. Version 3 of the native image identity binds the C source, exact compile/link arguments, actual gcc/cc1/as/collect2/ld paths, versions and hashes, dependency headers, traced linker inputs, object and Linux x86-64 PIE executable. Generated files live under `/opt/edge-reaper`, outside the byte-closed input tree. Each image qualification rechecks these hashes before the helper executes. The four frozen install inputs, Node 24.22.1/ABI 137 and native builder-child joins are unchanged. Image metadata alone does not qualify compilation.

The non-root C PID1 forks exactly one coordinator and execs the original Node argv/environment. An unnamed socketpair supplies only that coordinator with FD3. Node marks inherited descriptors close-on-exec; the existing child launches supply only stdio 0–2. Every C `recvmsg` resets its ancillary capacity and requires exactly one kernel credential record matching the original forked coordinator PID/UID/GID. Foreign credentials, ancillary truncation, extra rights, premature EOF, replay and malformed frames fail closed. The socketpair's creation-time peer credential is not sender authentication.

Private EDR1 frames are exactly 80 bytes: ASCII magic at 0–3, operation at 4, zero at 5–7, unsigned big-endian sequence at 8–11, coordinator namespace PID at 12–15, binary nonce at 16–47 and binary context hash at 48–79. Operations are HELLO=1, DRAIN=2 and FINISH=3; replies echo the exact request with bit 128 set. Sequence starts at one, cannot wrap, and only one request may be outstanding. No frame or control identity is forwarded to public diagnostics.

After original process CLOSE and monitor join, the coordinator requests DRAIN before the original final census. PID1's single waiter reaps with `waitpid(-1, WNOHANG)`, retries EINTR and acknowledges only a pass ending in zero while the coordinator remains alive. ECHILD with a supposedly live coordinator is a failure. ACK does not mean all workload retired: every remaining live or Z workload row still rejects qualification. RPC failures cannot skip the original final sample or replace original errors, including undefined. A held ACK is bounded by the existing outer owner lifetime, not a new completion timer.

Both parent admission visits bind PID1 and the coordinator separately by host/namespace PID correspondence, start identity, executable hash, original command/context, namespaces and cgroup. The census excludes only those two exact PID:start controls and requires observing both; reused, missing or zombie control identities fail. All other namespace processes remain counted. Builder parentage is bound to that authenticated coordinator. These sampled observations do not establish continuous ABA-free custody.

Handlers only latch signal flags; mask-aware waiting avoids lost wakeups. Main-loop termination forwarding targets only the unreaped forked coordinator. FINISH is acknowledged before Node deliberately closes FD3 and exits. Both failed and successful socket shutdown share one idempotent original-CLOSE join; destroy throws and late error events remain independent, including undefined. A missing CLOSE remains pending under the original outer lifetime. The reaper cannot successfully exit with unresolved children. Container process closure and independent physical cgroup retirement remain mandatory.
