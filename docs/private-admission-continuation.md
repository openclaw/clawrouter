# Private full-admission continuation candidate

**LOCAL CANDIDATE — PUBLICATION HELD.** Default admission, proxy, cache,
generation, provider and public routes are unchanged. This private continuation
uses the existing full 32 MiB ticket, the same Worker body counter, and the
independent DO arena. No profile, manifest or PR974 raw-reason API changes.
Local dependency-backed TypeScript, Node and Workerd semantics are unrun.

## Private dependencies and passive scratch

The private policy, routing, user, runtime and choice helpers preserve ordinary
exports and callers. Models keep the first 1024 unique strings in original order;
routing keeps the original valid unique prefixes and later empty properties.
User groups deduplicate raw values before trim/lower, so distinct raw values may
produce duplicate normalized outputs. Runtime windows and snapshots keep their
existing 128 limits, first-occurrence IDs and validation errors. Prospective
whole-result planning precedes generated output construction.

The new bridge adopts **PASSIVE_SCRATCH_DATA** inside its existing ticket. This
policy does not reinterpret PR974. It covers finite passive arrays, sets, maps
and plain records of admitted scalars or references to still-funded graphs.
For each simultaneous vector:

`D = 8 * (C + P + N) + 2 * U + B`

C counts distinct containers. P counts array/set entries and both key/value
cells for each object/map member. N counts each retained numeric, boolean,
null or undefined occurrence. U counts every retained key/value string occurrence
in UTF-16 units; equality, interning and string aliasing give no discount. B is
the entire owned byte backing. An object reference counts its cell and keeps the
referenced graph funded; a proved object alias does not create another container.
These are normative logical cells, not object sizes or physical heap estimates.

Execution and journal entries/indexes, promises, followers, callbacks, iterators,
visitor frames, listeners, terminal/failure metadata, Request/Response/controller
objects and arbitrary error graphs remain CONTROL. Scratch guards and leases
also remain CONTROL. Fixed byte views retain their existing explicit DATA channel.
No collection is free merely because it is temporary.

`reserveAdmissionScratch` checks the retained base plus every overlapping active
and retained lease before entering a factory. Growing generated-output plans
increase admission before construction. Returning data keeps its funding after
synchronous return. Joined hashes shrink atomically to the two retained hex
results; closed source reads shrink to their parsed result graphs. Unknown roots
hold the original ticket. No credit is released and reacquired while data lives.

The private selector funds ordinary quota arrays and its owned choice records,
then acquires an actual `PreparationAdmission` before shared configuration helpers.
The acquired owner bounds Env CSV, primitive, substitution, header and URL work.
The identity source budget does not cover Env. Preparation capacity escapes
ordinary configuration-error suppression as privately branded identity capacity;
ordinary missing configuration still excludes that candidate.

The ownerless Env CSV counterexample needed 33,554,456 logical bytes for split
and map alone. The private call no longer reaches that ownerless branch. The
bounded branch also funds up to 256 retained replacement references of 16384
units each before the shared helper's final output check. It does not assume
Cloudflare variable limits or string interning.

No fifteenth production file or global helper rewrite is needed for this policy.
The source and numeric tables below describe the implemented guards. They remain
subject to immutable source closure; static checks are not runtime qualification.

## Cumulative source and commit order

The seven inherited counters are bytes, text, values, containers, members,
entries and units. The DO adds actual request intake to the inherited source;
all KV and canonical SQL rereads consume that same budget. The Worker replaces
its unchanged sent prefix with producer cumulative counters once, then adds
its actual original reply consumption once. Prospective output planning is
separate; it does not create source credit or charge the prefix twice.

The full request graph stays funded through hydration. SQL preserves original
COUNT/LENGTH-before-value materialization. Cold credential lookup retains
canonical `credentials/id`, nullish-only genuine legacy fallback, initialization
fences and current winners before normalization. Staged aliases do not create
new source allowance.

The private typed ordered journal replaces per-record commit closures. It has
seed, projection, dependency, marker and selection variants, bounded at 231
entries. Dependency-only receipts and staged projections share the same at-most-98
pool slots; they do not add a second passive index. Seed
tables/columns are closed and allowlisted. Projection backfill reads one full
original KV record at a time, checks the captured pre-read revision against
current state, projects and clears that holder. Absence, null, legacy, pending
and revision mismatch stay distinct. The whole post-hash pool marks eligible
staged entries before a legacy early return.

All return paths perform final synchronous current credential, secret,
lifecycle, policy, owner, connections and pool rereads after the last await.
Stale routing choices are removed rather than committed. Every candidate read
captures its actual attachment revision, including null projections, unselected
candidates and snapshot-only results. Final synchronous validation probes every
retained dependency before serialization/effects. A mismatch removes selection,
snapshots and the planned selection journal entry. Earlier seed effects still
follow the existing journal contract; no rollback is claimed. A canonical winner
before the candidate read replaces an obsolete unpublishable staged projection
with its current dependency; repeated observations retain the first dependency. Unobserved,
unpublishable staging rows are not dependencies of a current choice. Observing
a canonical row converts such staging to a dependency receipt even if its
revision happens to match; eligible staged projections keep their own receipt. Complete result and
envelope planning includes actual consumer headroom before any journal effect.
The executor marks the journal attempted before its first write; the selection
entry marks itself attempted before cursor/count writes. An SQL error can leave
earlier effects; no rollback, compensation or replay is claimed. Final source
and routing compatibility still require bounded source review of the candidate.

Private history folds every accepted original SQL row directly into counts.
There is no history/pair array or `Object.entries(previous.counts)` batch.
The row maximum remains 32768, further constrained by remaining raw 2 MiB and
4H values, H containers and 3H members. It is not a 2048/98-row truncation.

Before a runtime state is normalized, a virtual complete partial-result plan
includes existing pools and the proposed normalized replacement. Defaults,
window copies and fact objects are not constructed before that plan passes.
The sparse 900-record / 32-window witness must reject generated expansion;
there is no window truncation or normalizer change. The complete final result

## Custody and bounded failure metadata

The bridge-only source owner immediately converts original acquisition, read,
FIRST-cancel and unlock outcomes into fixed categories, explicit primary
presence/undefined flags, origin bits and an ordered packed origin scalar.
It never traverses, copies, logs or stores an original rejected value. Same-origin
propagation is counted once; independent origins remain distinct even when raw
reasons are identical. The original PR974 source API is unchanged.

Generic InputRetirement receives sanitized followers that settle only after
their originals. Original read and FIRST cancellation are joined before original
unlock; late acquisition/body work is joined too. Reader, backing, decoder,
wire/text, parsed scratch and observer references are cleared before handoff.
UNKNOWN retirement holds all funding. A post-original-read abort check and a
post-join caller-abort check prevent final-read races from returning a handle.
Aborting after already-committed remote work is not a rollback promise.

Cleanup failure remains capacity 503 and overrides a primary. Transport failures
remain capacity 503; explicit limit/protocol categories and malformed JSON stay
distinct. Ordinary non-success authority responses are not recast as a successful
proof. Recognized private 503 envelopes regain the private local brand.

The finite claim covers application failure metadata. Native Promise/reader
internal reasons and engine reclamation are not bounded heap claims. Custom
JavaScript producer closures are application roots; they cannot be hidden in a
native exclusion. Tests own and release their synthetic gates separately.
