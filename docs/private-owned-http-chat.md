ordinary HTTP authentication, selection and credential-cache entrypoints remain
unchanged. The named compiled HTTP entry and pinned UNIFIED client witness are
implemented and registered, but the complete vertical is not qualified.
There is no deployment or public header/Env activation.

The request capability owns a positive charge in the existing common Worker

## Original upload custody

The private preparation branch registers an upload owner before constructing a
source or `FixedLengthStream`. It calls the source's original `pipeTo` directly,
observes its original promise immediately, and retains the fixed stream's
readable side for dispatch. The ordinary preparation branch keeps its existing

created before a later factory fails receives its own original cancellation.

and funding stay held. Successful fetch headers, a public response, a wrapper

The final request consumer joins the original roots before clearing source,
fixed-stream, listener and promise aliases. Independent upload failures retain
their origins, including `undefined` and two occurrences of the same Error.
The public response must not wait on its own encompassing completion.
