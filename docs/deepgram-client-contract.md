# Deepgram prerecorded client contract

The offline acceptance imports OpenClaw's actual registered ClawRouter media provider and `transcribeAudioFile` at public source `0066d51dff16526f9a3aa46c534047aba2632918`. The client uses its own ephemeral native install and SDK build; the fixture does not copy a parser or patch requests.

The compiled Deepgram Nova-3 offer drives native selection through a real Worker with SQLite authority and accounting objects. The source-owned 2,048-byte PCM WAV reaches the selected upstream unchanged; repeated native query values, Token authorization, current proxy-key scope and ordered complete tracks are asserted. Invalid input, absent proxy credentials and unknown whole-upload pricing under a hard-dollar budget remain closed before egress. An explicit seven-micro policy cost is distinct from upstream-dollar pricing; audio duration and channels never become token usage.

The actual client cases cover native selection only. The separate Worker runtime tests exercise native and manifest transports, authoritative post-upload checks, bounded intake, dispatch acknowledgment and response completeness. They do not establish manifest selection by this client.

Cancellation has two explicit observations: the actual host rejects its own abort without delivering a transcript; a guarded fixture signal then cancels the same pending Worker request and verifies reader closure, one original settlement and released capacity. The locked local runtime's physical pre-header disconnect propagation remains unqualified. Controlled cleanup is not a claim of live wire propagation.

All upstream responses and credentials are synthetic. No live inference, account entitlement or deployment of this candidate is established.
